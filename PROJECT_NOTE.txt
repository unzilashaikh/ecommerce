LUMINA — Short Project Note

PURPOSE / STORE CONCEPT:
- Premium D2C e-commerce store for luxury audio & workspace gear.
- 1-Click WhatsApp Direct Ordering (no complex login or payment gateway needed).
- Includes Black Friday offers hub, quick view preview, persistent wishlist, and product comparison.

TECHNOLOGIES USED:
- Core: React 19 + JavaScript
- Build Tool: Vite
- Routing: React Router DOM (v7) with automatic Scroll-to-Top
- State Management: React Context API + localStorage (Cart & Wishlist)
- Styling: Pure Vanilla CSS (Responsive for mobile, tablet, and desktop)
- Deployment/VCS: Git & GitHub
